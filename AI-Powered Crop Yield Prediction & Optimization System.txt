PROJECT ROLE
You are a Principal AI Product Architect, Senior Full-Stack Engineer, Machine Learning Engineer, UX/UI Designer, Data Engineer, DevOps Engineer, and Agricultural Technology Specialist.

Your task is to design and build a premium, production-style, responsive web application called:

"AI-Powered Crop Yield Prediction & Optimization System"

The application must simulate a complete end-to-end farmer experience rather than being a simple dashboard or static frontend.

The system should combine:
1. AI-powered crop yield prediction
2. Dynamic weather monitoring
3. RMC/IMD weather information integration
4. Weather-change detection
5. Dynamic farming-plan updates
6. Soil analysis
7. Irrigation recommendations
8. Fertilizer recommendations

10. Crop health monitoring
11. Farm management
12. AI agricultural assistant
13. Historical analytics
14. Notifications and alerts
15. Farmer-friendly explanations
16. Modern premium UI/UX
17. Responsive desktop/tablet/mobile experience

============================================================
1. CORE PRODUCT VISION
============================================================

Build a premium AI agriculture platform that behaves like a digital agricultural advisor for farmers.

The central concept is:

FARM DATA
+
WEATHER DATA
+
SOIL DATA
+
CROP DATA
+

+

+

+
RESOURCE OPTIMIZATION
        ↓
DYNAMIC FARM PLAN
        ↓
FARMER ACTIONS
        ↓
MONITORING + FEEDBACK
        ↓
PLAN UPDATED AGAIN

The farming plan must NOT be static.

Whenever important weather conditions change, the system must reassess the current farming plan and generate updated recommendations.

Example:

Original plan:
- Irrigation: Today
- Fertilizer: Tomorrow
- Harvest preparation: Friday

New weather information:
- Heavy rainfall expected

AI response:
- Irrigation postponed
- Fertilizer postponed
- Waterlogging risk increased
- Pest/disease monitoring increased
- Harvest recommendation recalculated

Display a clear "Plan Updated" event in the UI.

============================================================

The primary user is a farmer.

Design the application for a user who may not be technically advanced.

- use simple language
- avoid unnecessary technical terminology

- provide explanations for AI recommendations
- support Tamil-friendly content architecture in the future
- prioritize mobile responsiveness

Do NOT make the interface look like a generic SaaS admin dashboard.
